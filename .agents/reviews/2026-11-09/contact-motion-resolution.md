# D23 독립 검토 처리

두 검토는 fork_context:false의 native subagent에 명시한 파일만 제공했다. 부모 대화·메모리 검색 없이 검토하도록 요청했다. 공유 파일/호스트 지침까지 완전히 격리된 것으로 주장하지 않는다.

| 발견 | 처리 | 현재 증거 |
| --- | --- | --- |
| 같은 업데이트의 적 반격으로 접촉이 피격 자세에 덮임 | 수락. 새 접촉 직후 적 처리를 미뤄 한 번 반환; 확정 공격은 유지 | test_contact_boundary, before/after-timing frame60/66 |
| 긴 tick 안에서 새 hitstop을 전부 소비하여 접촉을 못 그림 | 수락. 새 접촉을 반환하고 남은 dt를 hitstop에서 차감; catch-up 없음 | 100ms 접촉 자세, 60/10/4fps 상한 검사 |
| 마지막 베기 회수의 클릭 소실 | 수락. 기존 회수 종료 뒤 첫 타 연결 | .54초 클릭 전후 실제 SDL/상태 JSON |
| 최저 허용 구간에서 예약 시간이 회수보다 먼저 만료 | 두 검토가 재현. 실패 검사 후 마지막 회수 동안 latch, 피격/패링/새 공격에서 해제 | 첫 허용 경계/중단 검사; 후속 독립 8시점 확인 |
| 저프레임 접촉 보존에 따른 추가 지연 | 명시적 절충. 한 렌더 간격 이내 추가 지연과 catch-up 부재를 검사하고 README/계획에 공개 | test_contact_presentation_has_bounded_delay_and_no_catchup_burst |
| 새 아틀라스 치수 오류 | 자동 계약 검사에서 실패. PNG의 실제1774×887로 수정, builder에서 확인 | 최종 전체 검사 통과 |

사후 검토의 240개 좌표 표본은 관절/반전/칼과 손의 등록 검사이며 자연스러운 움직임을 보증하지 않는다. 최종 사후 응답은 해당 수정 범위에서 추가 실행 결함을 보고하지 않았으며, 검토자는 native 실행/청취를 하지 않았다. native 최종 검사는 주 작업에서 `20261109-021345`로 별도 수행했다.
