# D24 화면·동작·음향 재구성

보존용 시안 기록이다. D28에서 사용자는 폰트와 UI/UX가 여전히 미달이라고 평가했다. 아래 맑은고딕/바탕·쇠 프레임 선택은 작업자의 D24 구현안이며 사용자에게 승인된 고정 미술 요구가 아니다. 후속 작업은 현재 사용자 피드백과 prompts/polish-pass.md의 채택 기준을 따른다.

사용자: 방향 이동 모션·UI·효과음이 여전히 시험용처럼 보인다. 평가가 좋은 공개 자료/스킬을 확인하고 기존 방식의 한계가 있으면 새로 만들 것. 글자만 흩어진 화면을 게임 UI로 바꾼다. 기존 전투 규칙은 유지한다.

Anthropic frontend-design 원문을 읽고 세계관 소재·명시적 색/서체/위계·정보를 전달하는 구조·불필요한 문구 제거·두 번의 시각 검수를 적용한다. CSS/웹 전용 구현은 적용하지 않는다. 정적 포스터만 출력하는 canvas-design과 엔진이 맞지 않는 Godot 스킬은 설치하지 않는다. 로컬 참고 원문/라이선스를 보존하며 전역 설치나 품질 인증으로 표현하지 않는다.

화면 방향: 먹색 칠(#151B24), 쇠색(#4F5260), 옅은 종이(#D7CFB4), 검붉은 칠(#963E3D), 마모된 황동(#BCA36B), 흐린 청색(#526B79). 무협의 칼집·인장·철제 장식에 맞춘 잘린 모서리, 절제한 문양을 사용한다. 맑은고딕은 설명, 바탕은 제목/보상에 사용한다. 같은 크기의 대시보드 카드 3개는 폐기한다.

좌상단 인물 문장/체력, 우상단 오르는 길 4지점, 좌하단 스타일/증강 인장, 우하단 검격·패링·회복 슬롯, 하단 중앙 보스 체력으로 전투 공간을 비운다. 보상은 큰 인장+고유색+효과 설명을 가진 선택물로, 제목/정지 메뉴는 같은 철제/먹색 표면으로 통일한다. 모든 긴 설명은 안내나 명시적 선택/호버 안에 둔다. 적 예고는 단어와 진행 막대 대신 무기 문장/진행 원, 피격 숫자는 짧게 유지한다. 색만으로 상태를 구별하지 않는다.

공개 원본: Game-icons.net/Lorc의 SVG를 출처·CC BY3와 함께 가져와 색과 테두리를 통일하고 native SDL용 PNG로 내보낸다. Kenney의 CC0 UI도 확인했으나 현재 세계관보다 범용 RPG/버튼 성격이어서 통째로 붙이지 않는다. Martial Hero(CC0, 제작자 페이지 평점4.9/5,39평가)는 동작 참고이며 주인공 디자인은 유지한다. 평가·설치 수는 확인 시점의 수치이며 결과물 품질의 보증으로 쓰지 않는다.

이동은 잘못된 그림 반복/고정 상체 리그를 성공으로 고집하지 않는다. 작가 제작 동작을 참고해 몸·옷자락이 같이 변하는 새 원화를 우선 검수한다. 음향은 이전 G의 EQ만 바꾸지 않고 다른 공개 원본으로 역할별 세트를 만든다. 실제 청취가 아니면 청취했다고 하지 않는다.

키보드/마우스 메뉴, 공중 공격/패링, 기존 접촉 처리와 회수 버퍼, 생존 증강 순서를 보존한다. 같은 장면의 전후 SDL 화면/영상, 입력과 한 판, 채널/음원 검사 후 ZIP을 갱신한다. 사용자 앱/플레이 창은 보존한다.
