# 검격·UI·레벨 통합 검수 프롬프트

이 게임의 개선 작업에 아래 절차를 적용한다. AGENTS·기획·최신 사용자 결정이 우선한다. 새로운 규칙을 만드는 문서가 아니다.

작업 선택은 coding-start, 선택한 검토의 증거 관리는 [증거 기반 검토](evidence-review.md)를 따른다. 별도 검토자가 없는 주 에이전트의 재독을 독립 검토로 바꾸어 말하지 않는다. 아래 설치/탐색 기록은 당시 결과이며 현재 설치 상태는 실제 스킬 경로에서 확인한다.

> 사용자의 최근 불만과 PRODUCT_REVIEW/QUALITY_REVIEW를 읽는다. 기능이 아니라 플레이어가 보고 듣고 판단하는 한 장면을 평가하라. 이번 검수의 행동은 무엇이며, 어떤 표시가 이를 돕거나 가리는지 먼저 적어라.
>
> UI: 전투 중 체력/회복, 현재 위치, 현재 조합을 구분한다. 보스의 성공 누적과 공격 기회가 드러나는지 본다. 같은 결과의 중복 글자와 원인 없이 겹치는 표시를 줄인다. 실제 크기의 한글 화면을 확인한다.
>
> 레벨: 지형의 역할을 공격·회피가 아닌 기존 점프/이동·패링과 연결한다. 발판이 장식인지 실제 전술 선택인지 확인한다. 현재 물리와 적의 판정으로 점프 도달·적중·피격이 모두 가능한지 재현한다. 새 적/새 조작이나 체력 증가로 문제를 덮지 않는다.
>
> 모션: 준비→접촉→회수와 첫/끝 연결을 실제 시간으로 본다. 좌우 방향·손/칼·발 접지·반대 다리 교차를 확인한다. 같은 자세를 늘린 시트는 개선으로 채택하지 않는다. 생성 프롬프트를 강화해도 해결되지 않으면 원본을 보존하고 실패 원인을 남긴다. 실제 피해/입력과 표시 시간을 분리해 새 잠금이 생기지 않도록 한다.
>
> 음향: 칼 질감·적중 밀도·반복 피로도 세 목표를 함께 유지한다. EQ를 바꾸기 전에 실제 재생 이름·채널·시작/종료·음소거·동시 재생을 추적한다. 보조음이 주 적중음을 끊거나 중요한 신호를 가리는지 확인한다. 원음 청취를 하지 못했다면 그 사실을 남기고, 같은 장면과 음량을 맞춘 비교본을 제공한다.
>
> 수정 전 캡처를 보존한다. 구체적인 차이를 고치고 같은 입력의 짧은 영상을 다시 만든다. 관련 회귀 검사와 SDL 메뉴·입력·한 판을 확인한다. 실제 수정, 기각한 가설/초안, 남은 체감 평가를 구분해 DEVLOG에 기록한다. 실행 ZIP은 AGENTS.md의 패키징 기준을 따른다. 테스트 수를 재미·완성도 점수로 바꾸지 않는다.

## UI·모션 채택 기준

- 기준 작품은 작품명만 적지 않고 적용할 실제 화면/짧은 장면을 확보한다. 사용자가 지정한 스컬은 배치, 산나비는 도트 방향 등 지정된 참고 역할을 유지한다. 아직 보지 못한 화면을 분석 완료로 쓰지 않는다. 외형 복제 대신 어떤 읽힘/동작 원리를 적용할지 구체적으로 적는다.
- 폰트는 제목·수치·효과 이름·설명의 역할과 실제 한글/숫자 크기, 굵기, 대비, 정렬을 함께 비교한다. 기존 OS 기본 글꼴을 확정안으로 취급하지 않는다. 모든 문구를 도트 글꼴로 바꾸는 것도 자동 합격이 아니다. 후보는 실제 게임 해상도와 배경에 적용해 읽힘과 세계관 적합성을 검토한다.
- 전투 HUD·보상·정지 화면을 같은 미술 기준으로 검수한다. 체력/회복/현재 선택이 구별되는지, 초점·확정·사용 불가 상태가 읽히는지, 피드백이 접촉과 캐릭터를 덮는지 확인한다. 프레임 장식 추가나 글자 잘림 검사만으로 UI 품질을 완료하지 않는다.
- 사용자가 미달로 평가한 시안은 미해결로 유지한다. 기존 틀의 작은 수정으로 원인을 해소할 수 없다면 폰트·프레임·원화·레이아웃을 교체한다. 기능 검증과 미감 판단의 완료 범위를 따로 기록하고, 핵심 불만이 남은 결과를 개선 완료로 포장하지 않는다.

## 사용 범위와 출처 확인

프로젝트 전용 검수문이며 지침을 읽거나 스킬을 설치한 사실은 결과물 품질 인증이 아니다. 실제 수행한 비교·수정·검증을 근거로 판단한다.

2026-11-08 find-skills로 skills.sh 후보와 원본 저장소를 확인했다. game-audio 후보에는 Web Audio API 전용 절차가 있었고, 확인한 범용 게임 디자인 후보는 사용 사례가 적었다. pico2d에 적합한지 충분히 확인되지 않은 패키지를 전역 설치하지 않았다. CLI 검색은 npm 도메인 이름 해석 실패로 완료하지 못했으며 웹 검색으로 원문을 확인한 범위만 사용했다. 외부 후보가 검증됐다고 추천하지 않는다.

- [검색한 game-audio 원문](https://www.skills.sh/hungify/playables-skills/game-audio)
- [확인한 게임 개발 스킬 원본 저장소](https://github.com/setcodes/gamedev-skills)
- 재사용의 기준은 설치 수보다 현재 게임에서의 재현·수정·검증 결과다.

### 보행 시트 채택 전
대표 캐릭터 한 주기를 게임 속도·양방향으로 출력한다. 같은 발의 신발·발싸개·무릎을 착지부터 다음 착지까지 추적한다. 지지발의 색이나 앞뒤 관계가 중간에 바뀌면 해당 칸을 특정해 수정하고 같은 입력으로 다시 캡처한다. 전후 영상·루프 GIF와 검토한 프레임 번호를 남긴다. 직접 재생해 본 범위와 정지 프레임에서 확인한 범위를 기록한다.
