# 벼랑 아래 칼날
 
절벽 아래로 떨어진 검객이 빼앗긴 도장으로 돌아가는 동양풍 횡스크롤 액션 게임.
현재 버전은 **일반 전투 3스테이지 → 2페이즈 보스 → 클리어 / 사망 후 재시작**까지 플레이할 수 있다.

## 실행

ZIP 전체를 압축 해제하고 `main.py`가 있는 폴더를 연다. Windows에 Python 3가 설치되어 있다면 이 폴더에서 터미널을 열어 아래 첫 줄로 pico2d를 설치한다. 이후에는 `run_game.bat`을 더블클릭하면 된다. `py` 명령이 없는 환경에서는 두 줄의 `py -3`를 `python`으로 바꾼다.

```powershell
py -3 -m pip install -r requirements.txt
py -3 main.py
```

이 PC에서는 Python 3.14 + pico2d 1.5.1로 실행을 확인했다. 다른 위치에서 실행해도 에셋은 게임 폴더 기준으로 읽는다. 실행 중 서버·인터넷 연결은 필요 없다. 글꼴은 게임에 포함한 갈무리9/11을 사용하며 별도 설치하지 않는다.

`view_motions.bat`에서는 ← / →로 주인공 모션 9종을 양방향으로 확인할 수 있다. 기존 창이 열려 있다면 닫고 다시 실행해야 수정 내용이 적용된다.

## 조작

| 좌클릭 | 클릭마다 1타. 추가 클릭으로 내려베기 → 올려베기 → 마무리 베기 연결 |

공격과 패링 모두 공중에서 사용할 수 있다. 공격 도중 패링으로 전환할 수 있다. 마우스 위치는 공격 방향에 영향을 주지 않는다. 회피·강공격은 없다.

## 한 판 구성

| 순서 | 전투 | 보상 |
| --- | --- | --- |
| 1 절벽 아래 | 검사 1명 → 검사 2명, 2전투 구역 | 혈인 / 반월 / 연참 중 1개 |
| 2 산길 | 창병 입문 → 검·창 혼합, 3전투 구역 | 무작위 증강 후보 3개 중 1개 |
| 3 도장 앞 | 검·창 혼합 → 앞뒤 협공, 3전투 구역 | 보유하지 않은 증강 후보 3개 중 1개 |
| 4 도장 | 도장주, 체력 50%에서 2페이즈 | 클리어 결과 |

스타일은 혈인(잃은 체력에 비례한 피해), 반월(패링 회복·기절), 연참(적중 중첩) 3종이다. 증강은 육참골단·잔영검·혈흔·간파·불굴·회생 6종을 구현했다. 효과의 충돌 처리와 상세 규칙은 [PRD](PRD.md)를 따른다.

한 번에 한 적이 공격을 시작하며 공격 준비를 글자·동작·막대로 알린다. 보스 2페이즈에는 연속 베기와 베기 후 찌르기가 추가된다. 반월은 보스에게 패링을 3회 성공해야 기절시킨다.

구역을 돌파하면 오른쪽의 다음 전투로 이동한다. 추가 적은 등장 표시 후 행동하며 화면 밖 적은 방향을 표시한다. 일반 실행의 증강 후보는 실행마다 고정된 난수열을 쓰지 않는다. 검증 모드만 재현을 위해 고정 시드를 사용한다.

제목·정지·결과 메뉴와 보상은 마우스/키보드로 조작한다. 첫 스테이지는 실제 입력에 맞춰 기본 조작을 순서대로 안내한다. 착지 직전과 발판 끝 점프에 짧은 입력 보정이 있다. 다른 창으로 전환하면 전투를 정지한다. 음량·음소거·흔들림·초기 안내 설정은 `%LOCALAPPDATA%/BladeBelowCliff/settings.json`에 저장되며 저장이 실패해도 게임은 계속 실행된다. 자동 검증은 이 개인 설정을 읽거나 쓰지 않는다.

## 이번 조작감 수정

현재 D31: 우클릭하면 양손으로 칼을 몸 앞에 세워 방어하고, 패링에 성공하면 칼을 바깥으로 쳐내는 몸 동작을 쓴다. 실패에는 쳐내기가 나오지 않는다. 기존 타이밍 판정과 공중 사용은 유지한다. 새 원화와 제작 요청은 [방어·쳐내기 제작 기록](assets/player/MOTION_GUARD_BEAT_V8.md)에 있다.

현재 D30: 패링은 팔만 움직이던 원화 대신 무릎·골반·몸통·망토가 함께 움직이는 자세를 쓴다. 실제 성공 때 충격 자세를 표시하고 헛패링은 방어를 풀며 복귀한다. 판정이 유효한 동안 방어 자세를 유지한다. 달리기는 새 시트의 양발 지지 자세6개를 선별해 발/손/장검 기준점을 맞췄다. 세부 제작 요청과 시안 선별은 [몸 원화 제작 기록](assets/player/MOTION_GENERATION_V7.md), 실행/미확인 평가는 [품질 기록](QUALITY_REVIEW.md)에 있다.

D29: 한글 픽셀 서체를 게임에 포함하고 제목/수치/설명 역할을 나눴다. 전투 HUD는 지면 아래의 체력·스타일·증강·회복과 상단 보스/진행 정보로 재구성했다. 금속 장식 프레임을 먹색 면과 검붉은 강조로 바꾸고 보상·메뉴의 선택 표시를 강화했다. 긴 효과 설명은 실제 서체 폭으로 줄바꿈한다. 클릭/ENTER 확정과 숫자 바로 확정을 안내하며 기존 입력 방식은 유지한다. 패링 접점의 정보 표식은 걷어냈다. 당시 남겨 둔 패링/달리기 원화는 위 D30에서 교체했다.

현재 D26: 보는 방향으로 시야가 열리도록 카메라를 조정했다. 검격은 고정된 넓은 효과 대신 실제 칼끝 경로의 얇은 잔상을 사용하며 적중 절삭광·패링 충격파·발판/점프 높이에 맞는 그림자를 추가했다. 일반 적은 회수 초반의 짧은 틈 뒤 다음 적이 공격을 준비한다. 동시에 공격을 준비/실행하는 적은 한 명이고 보스 연속 패턴은 유지한다. 그림자/잔상에 필요한 그래픽 기능을 지원하지 않으면 기존 검격 표현으로 계속 실행한다.

Python/pico2d 외 모듈도 사용할 수 있다. 이번 새 모듈 imageio-ffmpeg는 전후 검증 영상 제작 도구로만 설치했으며 게임 실행에 추가 설치할 필요는 없다.

현재 D24: HUD·제목·메뉴·보상·결과를 먹색/쇠 재질 프레임과 능력 인장으로 재구성했다. 긴 설명은 보상·도움말·인장 호버 안에서 확인한다. 전투 중에는 체력·오르는 길·스타일/증강·회복/검격/패링 슬롯과 보스 게이지가 중심이다. 적 공격 예고는 무기 문장과 차오르는 원으로 표시한다.

사망 결과에는 마지막 피격의 적·공격·방어 상태를 표시한다. 뒤쪽 피격, 패링 유효시간 종료, 이미 소모한 방어, 육참골단 피해를 구분하며 기록하지 못한 정보는 추정하지 않는다. 보상 화면의 도움말은 닫은 뒤 같은 후보로 돌아온다. 육참골단은 불굴·회생으로 살아남은 경우 반격이 가능하다.

프레임 경과 시간은 한 번에 최대 0.25초까지 처리한다. 기존 0.05초 상한 때문에 10fps에서 일반 진행이 절반으로 느려지던 문제를 수정했다. 적중 순간에는 반드시 접촉 자세를 한 번 보여 주고 다음 갱신에서 상대 공격/회수를 진행한다. 저프레임 전투에서는 명목상 정지 시간보다 최대 한 렌더 간격 정도 더 지연될 수 있으며 남은 시간을 몰아 처리하지 않는다. 4fps 미만이나 긴 일시 지연에서의 시간 절삭은 여전히 보호 상한의 제한이다.

최근 통합 보완에서는 체력 감소 잔상과 반월 보스 패링 누적을 표시했다. 낮은 발판은 지상 적과 서로 공격이 닿는 높이로 조정하고 높은 발판의 연결 간격을 정리했다. 육참골단은 기존 마무리 베기 자세로 반격을 보여 주며 입력 잠금을 늘리지 않는다. D23의 고정 상체 리그는 D24에서 전신 시트로 교체했다. 옷자락과 다른 자세의 연결은 같은 입력 비교와 사용자 피드백으로 계속 검수한다.

잔영검 소리는 별도 보조 채널을 사용해 본타의 적중음을 중간에 끊지 않는다. 패링 때 남은 칼바람은 정리하고 육참골단의 반격 소리를 구분한다. 원음 선택과 청취 만족은 채널 동작 검사와 별개다. 작업에는 [통합 검수 프롬프트](prompts/polish-pass.md)를 적용한다.

- 기본 공격에 다른 몸 모션을 쓰는 3연격과 다음 공격 입력 예약을 적용했다. 짧은 클릭은 1타, 다음 클릭이나 유지 입력으로 후속타가 이어진다. 마지막 베기 회수 끝의 .32초 안에 새로 누른 클릭도 보존하며 기존 회수를 마친 뒤 첫 베기로 연결한다. 피격·패링으로 중단하면 예약을 취소한다. 준비·휘두름·회수 동안 칼 각도를 이어 주고, 전진·피격 밀림은 여러 프레임에 걸쳐 움직인다.
- 타격 순간의 짧은 정지, 적 밀림, 검격 궤적, 패링 불꽃을 적용했다. 화면 흔들림은 끌 수 있다.
- 달리기는 몸·다리·망토·허리띠가 함께 변하는 전신6개 자세(.56초)다. 새8장 중6개를 선별/재배열하며 실제 이동 거리로 진행하므로 벽에 막히면 멈춘다. 기존 분리 리그는 사용하지 않는다.
- 새 검격·적중·패링·UI선택음과 발소리·점프·착지음14개를 다른 CC0 게임용 소스로 제작했다. 발소리는 지상 이동 주기에 맞추고 점프·공중·정지·공격 중에는 재생하지 않는다. 착지는 같은 순간 발소리를 겹치지 않는다. 이동음은 독립된6번째 채널에서 낮게 재생하며 검격을 끊지 않는다. 기본 음량15%와 개인 설정을 유지한다. 소스·편집·측정 및 실제 청취의 구분은 [에셋 출처](assets/CREDITS.md)에 기록했다.
- PixelFX에서 내보낸 효과 시트를 사용한다. 실행할 때 Node나 PixelFX 설치가 필요하지 않다. 출처와 이용 조건은 [에셋 출처](assets/CREDITS.md)에 기록했다.

## 검증

```powershell
py -3 -m unittest discover -s tests -v
py -3 main.py --input-check --report verification/input.json
py -3 main.py --ui-check --quiet-check --report verification/ui.json
py -3 main.py --autoplay --fast --capture-dir verification/screens --report verification/loop.json
py -3 tools/polish_check.py --runtime
py -3 tools/audio_channel_check.py --report verification/audio-channels.json
```

전투 검증은 일반 조작 입력으로 진행하며 체력·피해를 덮어쓰지 않는다. 입력 검증은 SDL 이벤트 큐에 키보드·마우스 이벤트를 넣어 시작·이동·점프·3연격·패링·일시정지·재시작 경로를 확인한다. 실제 사람의 난이도 평가나 모션 품질 평가를 대신하지 않는다.

## 파일 구성과 남은 다듬기

`main.py`는 실행과 입력, `bladegame/core.py`는 전투와 진행, `bladegame/render.py`는 화면과 소리, `bladegame/config.py`는 주요 수치와 스테이지 구성을 담당한다. `tools/`는 에셋 제작용이며 게임 실행에는 필요하지 않다.

기획 PPT의 기본 기능 20항목을 구현했다. 보스 찌르기·기절·2페이즈 자세, 돌/목재 지형, 출혈 입자와 반복 검증을 보완했다. 일반 배경과 적의 핵심 자세는 재사용한다. 모션 연결, 난이도와 소리는 실제 피드백으로 계속 조정한다. 컨티뉴·추가 적·추가 증강은 확장 범위다.

기획 대비 증거는 [구현 현황](IMPLEMENTATION_STATUS.md), 사용자 의도는 [결정 기록](DECISIONS.md), 만든 방법·수정 이유는 [개발 기록](DEVLOG.md)에 남긴다. `AGENTS.md`와 `blade-game-polish` 스킬이 작업 절차에 연결한다. 반복 검증은 숨김·음소거로 실행하고 모션·입력·완주·음원 수치를 `verification/polish/latest.md`에 기록한다. 시각·청취·난이도 평가는 자동 통과로 대체하지 않는다.

[자체 피드백·작품 비교](QUALITY_REVIEW.md)는 대화에서 확인한 목표, 맞지 않았던 시안, 참고 장면과 현재 게임의 차이, 적용한 수정과 남은 항목을 연결한다. 최근에는 첫타 준비 자세, 실제 접촉 위치의 불꽃, 대기 중 적의 발 움직임, 착지 후 달리기 연결, 패링 성공 표시와 기존 강화 검격의 구분을 보완했다.

[판매 관점 검토](PRODUCT_REVIEW.md)는 첫 플레이부터 재도전까지 전체 경험을 점검한다. 최근에는 전투 배치·진행 안내, 산길/도장 앞 별도 배경, 보상 상세와 메뉴·설정을 개선했다. 현재 배포물은 Python 설치가 필요한 소스 ZIP이며 소비자용 설치본이나 상업 출시 완료본이 아니다.

[증거 기반 독립 검토](prompts/evidence-review.md)는 EGM·Ponytail 원문을 참고해 설계/코드/실행 근거를 나눠 확인한다. 원문과 라이선스는 프로젝트 안에 보존했고 글로벌 플러그인/훅은 설치하지 않았다. 독립 검토는 native subagent가 있는 실행에 한하며, 자동 테스트와 사람의 청취·재미 평가는 별개다.
